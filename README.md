# Hibernate Many-To-Many Mapping (Employee - Project)

This project demonstrates Many-To-Many relationship mapping using Hibernate ORM with Employee and Project entities.

# Tech Stack

* Java
* Hibernate (JPA Annotations)
* MySQL
* Maven

# Features

* Add Employee
* Add Project
* Assign multiple projects to an employee
* Demonstrates `@ManyToMany` mapping with join table

# Learning

* Many-To-Many mapping in Hibernate
* Join table concept
* Entity relationship management
